# International Transfer Pre-submit Checklist

- [ ] Beneficiary name matches current bank instructions
- [ ] Beneficiary address confirmed if required
- [ ] Receiving bank name confirmed
- [ ] Receiving bank address confirmed if required
- [ ] SWIFT/BIC confirmed from current bank instructions
- [ ] IBAN/account number confirmed
- [ ] Local routing identifier confirmed if required
- [ ] Intermediary/correspondent bank confirmed if specifically provided
- [ ] Currency confirmed
- [ ] Amount confirmed
- [ ] Payment purpose/reference confirmed
- [ ] Charges option reviewed
- [ ] No unexplained conflicts remain
- [ ] Bank confirmation/reference saved after submission
