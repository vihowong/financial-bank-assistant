# Transfer Workflow Reference

## Discovery phase
Collect only what is needed:
1. Sending country.
2. Receiving country/region.
3. Sending bank if known.
4. Receiving bank if known.
5. Currency.
6. Transfer type/channel if known.
7. Sender type (individual/company) when relevant.
8. Beneficiary type (individual/company) when relevant.

## Required-information categories
Possible categories:
- Beneficiary legal/name information.
- Beneficiary address.
- Beneficiary account number or IBAN.
- Receiving bank name/address.
- SWIFT/BIC.
- Local routing identifier.
- Intermediary/correspondent bank details when specifically provided.
- Currency and amount.
- Payment purpose/reference.
- Charges option, if the bank asks.

Never mark every category as universally mandatory. Determine the final list from the bank's current instructions.

## Pre-submit checklist
1. Match beneficiary name exactly to the receiving bank record/instructions.
2. Check the account/IBAN carefully.
3. Check BIC/SWIFT against current instructions.
4. Check local routing fields if requested.
5. Check currency.
6. Check payment purpose/reference.
7. Review charges option.
8. Review any intermediary-bank details supplied by the beneficiary bank.
9. Confirm destination country and beneficiary bank.
10. Save the bank confirmation/reference after submission.

## Troubleshooting categories
When a payment is rejected/returned, classify the issue before suggesting a fix:
- Identifier mismatch.
- Beneficiary mismatch.
- Account/IBAN issue.
- Missing local routing field.
- Intermediary bank issue.
- Currency/corridor restriction.
- Name/address formatting.
- Compliance review.
- Bank-specific receiving restrictions.

Do not assert the cause without evidence.
